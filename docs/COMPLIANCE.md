# Compliance

This project aims to be compliant with

## Protocol

### Telephony

 - ITU-T E.164 (1984)

### TRIP

 - RFC 2871 (2000) A Framework for Telephony Routing over IP
 - RFC 3219 (2002) Telephony Routing over IP (TRIP)
 - RFC 5115 (2008) Telephony Routing over IP (TRIP) Attribute for Resource Priority
 - RFC 5140 (2008) A Telephony Gateway Registration Protocol (TGREP)

### HTTP (REST)

 - RFC 2616 (1999) Hypertext Transfer Protocol -- HTTP/1.1

### ENUM

 - RFC 6116 (2011) The E.164 to Uniform Resource Identifiers (URI) Dynamic Delegation Discovery System (DDDS) Application (ENUM)
 - RFC 1035 (1987) DOMAIN NAMES - IMPLEMENTATION AND SPECIFICATION

## Code

 - ISO/IEC 9899:2011 (C11)

## Text and documentation

 - ISO/IEC 10646:2020 (Unicode UTF-8)
 - W3C HTML5
